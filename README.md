# Rotating Navigation

A small front-end project that demonstrates an animated rotating navigation menu. Use the menu buttons to rotate the article panel and reveal the navigation links.

## Features

- Animated circular menu button
- Article panel rotation when the menu is opened
- Navigation links slide into view with staggered transitions
- Responsive article image
- Font Awesome icons

## Built With

- HTML5
- CSS3
- Vanilla JavaScript

```text
Rotating-Navigation-Project-3/

```

## Run Locally

No installation or build step is required.

1. Download or clone this repository.
2. Open `50/index.html` in a web browser.
3. Click the menu icon to open the navigation, and click the close icon to hide it.

You can also open the project folder in an editor such as Visual Studio Code and run it with a local development server.

## External Resources

The page loads the Lato font from Google Fonts, Font Awesome icons from cdnjs, and the article image from Unsplash. An internet connection is required for these resources to load.
